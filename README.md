# Real Estate Agency Portal

## Setup Instructions

1. Install XAMPP
2. Start Apache and MySQL in XAMPP
3. Open phpMyAdmin at http://localhost/phpmyadmin
4. Create a database called real_estate_portal_db
5. Import the SQL script from the sql/ folder
6. Copy the project folder to /Applications/XAMPP/htdocs/
7. Open your browser and go to http://localhost/FinalStarterProjectS26/

## Features
- Register and login as agent, buyer, or renter
- Browse property listings
- Submit inquiries on properties
- Agents can add new properties
- Dashboard for logged in users
